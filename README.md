# FloraVision 🌿

FloraVision is a modern React-based frontend web application focused on showcasing products with a clean and responsive user interface.

The project features product cards, customer reviews, responsive layouts, and modern UI components built using React and Vite.

---

## 🚀 Live Demo

👉 https://floravision.netlify.app/

---

## ✨ Features

- Responsive modern UI
- Product showcase section
- Customer reviews section
- Reusable React components
- Mobile-friendly design
- Fast development with Vite

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/arjit03/FloraVision.git
```

### Navigate to project folder

```bash
cd FloraVision
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:5173
```
